# GYMTRX

A quiet gym logbook for Android. It records which days you trained and what you did, and nothing else: no streaks, goals, reminders or nudges.

| Folder | Version | Design |
|---|---|---|
| [`v2/`](v2/) | 2.0.0 | Light sage and dark themes, dot-matrix type and body map, illustrated welcome page |
| [`v1/`](v1/) | 1.0.0 | Dark OLED theme, Geist type, volt accent |

Each folder is a complete Flutter project. Build it from inside its folder; see its own README. Both share the app id, database and signing key, so 2.0 installs over 1.0 as an update and keeps your history.
